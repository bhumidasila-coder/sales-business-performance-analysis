# Sales & Business Performance Analysis

## Project Overview
An Excel-based data analytics project focused on analyzing sales and business performance to identify trends, evaluate profitability, and understand customer and product performance.

## Objectives
- Analyze overall sales, profit, and quantity.
- Compare performance across categories, regions, and customer segments.
- Identify top-performing products and customers.
- Evaluate yearly performance and profitability.

## Tools Used
- Microsoft Excel
- Data Cleaning
- PivotTables
- Pivot Charts
- Excel Dashboard

## Analysis Performed
- Basic Sales & Profit Analysis
- Category Analysis
- Region Analysis
- Sub-Category Analysis
- Year-wise Analysis
- Segment Analysis
- Product Analysis
- Customer Analysis

## Dashboard
The project includes an Excel dashboard for viewing key business performance metrics and analysis.

## Key Learning Outcomes
- Organizing and analyzing structured datasets.
- Using PivotTables and Pivot Charts to summarize business data.
- Identifying sales and profitability patterns.
- Presenting findings through an interactive Excel dashboard.

## Project Status
Excel analysis and dashboard completed. Advanced analysis and further enhancements are planned.
